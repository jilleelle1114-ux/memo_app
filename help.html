TreeMo 使い方ガイド

TreeMo（ツリーモ）は、階層構造で直感的にメモやテキストを管理できるツリー型メモ帳アプリです。

1. 基本的な操作

  • メモ・フォルダの作成： サイドバー上部の「📁+ フォルダ」「📄+ メモ」ボタンから作成できます。
  • 名前の変更・削除： 項目を選択した状態で「✏️ 名前変更」や「🗑️ 削除」をクリックします。
  • ドラッグ＆ドロップ： メモやフォルダをドラッグして、別のフォルダへ直感的に移動できます。（Ctrl キーを押しながらドラッグするとコピーになります）

2. ファイルの読み込みと同期

  • ファイル・フォルダ選択： PC内の `.txt` ファイルやフォルダ構造をそのまま読み込んで読み書きできます。
  • ローカル同期先フォルダを選択： 同期先フォルダを指定しておくことで、作成したメモ群をまとめてPC上のフォルダへ出力可能です。

3. ショートカットキー一覧

ショートカット 機能
Ctrl + F 全メモからのキーワード検索パネルを開く
Ctrl + S ローカルフォルダへの一括保存を実行
F2 選択中ツリー項目の名前を変更
Delete / Backspace 選択中ツリー項目を削除
Ctrl + C / X / V ツリー項目のコピー / 切り取り / 貼り付け
↑ / ↓ ツリー項目の上下選択移動
Esc 検索パネルやモーダルダイアログを閉じる

⚠️ データの保存に関する注意点

TreeMo のデータは外部サーバーではなく、お使いのブラウザ内（LocalStorage）に保存されます。

ブラウザの閲覧履歴削除などで「Cookieやサイトデータ」を消去するとメモが失われる可能性があります。定期的に右上「💾 ローカルフォルダへ一括保存」でバックアップをとることを推奨します。
